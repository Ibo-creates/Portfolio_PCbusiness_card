# Portfolio_PCbusiness_card
A maker portfolio card on a PCB with programmable NFC , QR code , contact details, an indication led and art on both sides. 

I have a maker conference coming up and I thought it would be so nice to make a pcb portfolio card to quickly give everyone my contact info and things about myself, while showing the actual PCB. 

**How it works:

When someone brings there phone near the card, current is induced in the antenna coil inside the PCB, which powers the nfc chip sending back a link to the phone and powering the indication led.
